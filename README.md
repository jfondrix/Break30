Break reminder for windows.
Reminds to take a break for 3 minutes every 30 minutes.

Comes as tray icon, you can right click to exit.


Reminders only run during working hours: from 06:00 to 18:30 local time by default.
To change either time, right-click the tray icon and pick **Start Reminders At** or
**Stop Reminders At** (a preset time, **Custom...**, or turn the limit off). The choice is
saved to `startRemindersAt` / `stopRemindersAt` in `settings.json` next to `Break30.exe`,
which you can also edit by hand (restart Break30 afterwards).
"Start Break Now" from the tray menu still works outside those hours.
